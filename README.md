# Agash & Deepika Wedding Website

## Deploy to Vercel (via GitHub)

1. Upload all these files to a GitHub repository
2. Go to vercel.com, sign in with GitHub
3. Add New -> Project -> Import this repo
4. Vercel auto-detects Create React App settings
5. Click Deploy

That's it! Live at your-project.vercel.app

## Run locally
```
npm install
npm start
```
